Where can I restore an Export Data JSON file? Choose Import Data beside Export Data in your user settings, or on the Accounts page. Preview and restore the accounts, activities and cash together. For a partial restore, select only the required accounts; both sides of a transfer must be included. CSV files use the separate activities and Cash Balances importers. Which CSV should I use for cash movements? Use Import CSV and Export CSV in Accounts → Cash Balances for deposits, withdrawals, reconciliations and linked cash entries. The activities CSV remains for financial activities. When restoring both, import financial activities first, then the cash journal. Does reconciliation add money to my account? No. Reconciliation sets the cash balance to the actual amount on the selected date. Enter 380 to set the balance to 380, even if a different balance was previously calculated. Its fee must be zero. Why can cash differ between portfolio charts? The account preference for including cash in portfolio analysis is separate from Update Cash Balance, which controls activity cash effects by default. A chart may also hide cash. A value explicitly labelled Cash still shows recorded cash. Deposits and withdrawals do not themselves represent investment performance. What is Ghostfolio? Ghostfolio is a lightweight, open source wealth management application for individuals to keep track of their net worth. The software empowers you to make solid, data-driven investment decisions. What assets can I track with Ghostfolio? With Ghostfolio, you can keep track of various assets like stocks, ETFs, bonds, cryptocurrencies and commodities. What else is included in Ghostfolio? Please find a feature overview to manage your wealth here. Which calculation method does Ghostfolio use for performance? Ghostfolio uses the Return on Average Investment (ROAI) calculation method based on the average amount of capital invested over time. ROAI aims to provide a more insightful view of investment performance than simpler approaches, especially when contributions are made over time. Dividends are included in the calculation (total return). How can I import activities from Interactive Brokers (IBKR)?
  1. Log in to your Interactive Brokers Client Portal
  2. Navigate to Performance & Reports in the top menu, then select Flex Queries
  3. Click the + button next to Activity Flex Query
  4. Select Trades under Sections
  5. Select Executions on the pop-up window
  6. Click SELECT ALL and then Save
  7. Enter a Query Name (e.g., "Ghostfolio Export")
  8. Under Delivery Configuration, set Format to CSV, Include header and trailer records to No, Include column headers to Yes and Display single column header row to Yes
  9. Click Create
  10. Run the Activity Flex Query
  11. Under Period, select Custom Date Range and choose the dates you want to export. Run separate exports for longer histories if necessary
  12. Set Format to CSV, click Run and download your trades
  13. Import the CSV file in Ghostfolio: Portfolio → Activities → Import Activities...

Please note: The export contains trades only. It does not contain dividends, interest or taxes. Keep only rows with the asset class STK. Remove all other rows before the import, for example currency conversions (CASH, such as EUR.USD). Symbols from exchanges outside the US might need a manual change.
